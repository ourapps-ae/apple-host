# Source mapping

Reference revision: `19905b75dbea89fbfd424d67fe26c81aaed0e018`. Recipe paths are under `OurPoker/recipe/ios/`.

- `OurPoker/Sources/OurPokerApp.swift` lines 3-18 (the `@main` app, dark scheme, tint, scene-phase resume and pause) -> `implementation/apple/Sources/ApplicationShell.swift`: the fixed `TableModel`, `RootView`, `Palette.gold` and poker callbacks become `ShellConfiguration` (display name, tint, colour scheme, two callbacks); the scene is a reusable `ApplicationShell` instead of an `@main` type. Lines 20-123 (`RootView`: screen choice, help bulb, video overlay, guides, beginner prompt, tvOS exit chain) and lines 125-135 (`Palette`) are poker screens and colours and stay with the recipe and the theme component; only the Menu-button hook (lines 110-121) is kept as the `shellExitCommand` modifier.
- `OurPoker/Sources/Platform.swift` lines 7-15 (`uprightBoard`) and 17-41 (`tableStatusBarHidden`, `playerNameInput`, `platformButtonStyle`) -> `implementation/apple/Sources/Platform.swift`: the compile-time conditions are also expressed as `PlatformFamily` and `PlatformTraits` data so each screen asks one question, with the family chosen once from the build (tvOS, Catalyst or macOS, iPad or iPhone idiom). Modifiers are renamed `shellStatusBarHidden`, `shellNameInput`, `shellButtonStyle`; they now compile on macOS (iOS-only calls moved under `os(iOS)`), which the original did not. `RoomMode` (lines 3-5) is display-mode and stays with that component.
- `OurPoker/Sources/ApplicationSettings.swift` lines 1-3 (a generated `updatesEnabled` flag) and `OurPoker/Sources/TableModel.swift` line 148 (server address from defaults or Info.plist `OurPokerServerURL`) -> `implementation/apple/Sources/ShellSettings.swift`: display name, bundle identifier and server address are read from Info.plist, with the same defaults override (`serverURL`); the key is `ShellServerAddress`. The updates flag belongs to store-update and is left behind.
- `project.yml` lines 1-158 -> `implementation/apple/templates/{project.yml,app-target.yml,mac-settings.yml,tv-target.yml,scheme.yml}.template` and `implementation/apple/render.ts`: the two application targets (iOS plus Mac Catalyst, tvOS), their signing settings, sandbox and hardened runtime settings and schemes are kept; names, bundle identifier, deployment versions, component source folders, packages, server address and signing variable prefix become settings or options; targets are included or left out by the `targets` setting; the unit-test, interface-test and component-test targets (lines 94-130, 140-157), the `OURPOKER_TEST_SERVER_ADDRESS` variable and the fixed poker sources and the `./sync-art.sh` pre-generation command (an option now) are left behind.
- `OurPoker/Info.plist` lines 1-45 -> `implementation/apple/templates/Info.plist.template`; `OurPokerTV/Info.plist` lines 1-16 -> `InfoTV.plist.template`: names and version come from build settings; the camera and microphone texts, background modes, orientations and server address key are options; the poker wording is replaced by neutral defaults.
- `OurPoker/MacCatalyst.entitlements` lines 1-18 -> `implementation/apple/templates/MacCatalyst.entitlements`: copied verbatim.
- `ExportOptions-tvos.plist` lines 1-12 and `ExportOptions-macos.plist` lines 1-13 -> `implementation/apple/templates/ExportOptions.plist.template`: one template, with the installer certificate line for Mac only and the bundle identifier as a token; `TEAM_ID` and `PROFILE_NAME` placeholders are kept. An iOS export file is added (`generated-platform`: no recipe counterpart; same keys as the tvOS file).
- `OurPokerTV/Assets.xcassets/**/Contents.json` (13 files plus the catalogue root) -> `implementation/apple/templates/tv-assets/`: structure only; the PNG images are artwork and are left behind.
- `implementation/apple/render.ts` is new (settings validation with the aepm grammars, target and deployment parsing, template filling, `renderApple`/`writeApple`; recipe target names ios, macos, tvos map to iphone, ipad, mac, tv, web, android, windows are ignored, `renderApple` returns `{files, message}`); `tests/apple/generate.ts` and `tests/native.py project` are new checks.

Left behind: all screens, `Model.swift`, `TableModel.swift`, strings and localisation, sounds and art, `prepare-project.py` (Package.resolved copy), `sync-art.sh`, the tests under `OurPokerTests/`, `OurPokerUITests/` and `VerificationSupport/`, the app icon catalogue under `OurPoker/Resources/Assets.xcassets`.
